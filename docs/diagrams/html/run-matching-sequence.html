Sequence · POST /campaigns/{id}/run-matching

Run matching: request sequence

A single synchronous request. The router delegates to run_campaign_matching, which owns every call below. Returns are omitted except the final response; Gemini and Groq failures fall back to token Jaccard similarity and a heuristic rationale respectively, so the request still completes.

Idempotent

Rerun replaces, never appends

Old ai_match_scores rows are deleted and committed before scoring, so a rerun always reflects the current creator pool.

Cost control

Embeddings only when needed

The campaign is embedded once. Creator text is embedded only when the exact niche score is 0 and the campaign niche is specific. Vectors are never stored.

Scoring

LLM after ranking

Groq is called only after the deterministic sort, for LLM_RATIONALE_TOP_N = 5 matches. It rewrites the explanation and cannot move a creator's rank.
