Layer stack · backend/app

FastAPI backend layers

Domain-driven layout: every domain folder carries router.py, service.py, schemas.py and models.py. Routers only parse and respond; all logic sits in the service layer. Scoring lives in services/, which is called from campaigns/service.py.

Rule

No cross-domain imports in routers

A router talks only to its own domain service. Cross-domain work (matching, semantic, LLM) goes through services/, reached from the campaigns service.

Single source

matching_config.py

SCORE_WEIGHTS, budget buffer (1.3×), semantic threshold (0.28) and cap (0.40), TOP_MATCH_LIMIT = 10, LLM_RATIONALE_TOP_N = 5.

Also mounted

webhooks/ · youtube/

webhooks/ syncs Clerk users; youtube/ is a stateless public-API wrapper whose enrichment is persisted by creators/.
