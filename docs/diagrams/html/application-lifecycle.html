State machine · campaign_applications.status

Campaign application lifecycle

The offer-driven deal flow lives on the application, not the campaign. Every offer or counter writes a negotiation_turns row; only the other party's latest turn can be accepted. The contract is drafted on the first offer and activated on acceptance.

Offers

send_offer guards

Campaign must be active; application must be shortlisted or pending (a direct offer skips the shortlist). Counters require invited or pending_agreement.

Declines

Who declined is recorded

decline_offer writes rejected when the brand declines and declined when the creator does. withdrawn is set only through the brand's generic status update.

Capacity

Auto-reject on fill

When accepted applications reach number_of_creators, remaining shortlisted applications are rejected with “Campaign capacity has been filled”.
