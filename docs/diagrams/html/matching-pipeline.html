Matching engine: five-stage pipeline

Hard filters run first and are never rescued. Only creators whose exact niche score is zero get a semantic second chance, and that path can add at most 0.40 to the niche signal. Creators that fail the semantic threshold are held back and used only if strict matching returns nothing.

Stage 1

Budget gate

Exact rate-card totals per deliverable_code × quantity when available; cheapest active platform card next; follower-tier estimate last. Hard ceiling is max budget × 1.3 (BUDGET_RATE_HARD_CAP).

Stage 2

Competitor conflict

Same brand_category, different brand, collaboration within CONFLICT_LOOKBACK_DAYS = 90 → excluded before scoring. Unregistered past brands with no category pass through.

Stage 5

Deterministic ranking

Ties break on follower count, then creator id, so reruns give identical order. Previous scores for the campaign are deleted before the new top 10 are inserted.
